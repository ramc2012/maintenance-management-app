System Overview

The Maintenance Management System is a comprehensive platform managing all aspects of industrial maintenance at ONGC Ankleshwar Asset. It consists of 20 integrated modules covering equipment management, work orders, logbooks, calibration, audits, procurement, and more.

Getting Started

  1. Login with your credentials at the login page
  2. You will land on the Hub Page showing all module tiles
  3. Click any module tile to navigate to that module
  4. Use the sidebar to navigate within each module
  5. Use the ? icon in the top bar to return to this guide
Tip: Each module has a sidebar with sub-sections. The sidebar collapses on smaller screens. Click the menu icon to toggle it.

Equipment Master

Central registry for all mechanical and electrical equipment across installations.

Viewing Equipment

  1. Navigate to Equipment Master from the hub
  2. Click Equipment Registry in the sidebar
  3. Use the tabs: Mechanical, Electrical, Instruments
  4. Use the installation and status filters to narrow down
  5. Click any equipment tag to view its full details

Adding New Equipment

  1. Go to Equipment Registry and select the appropriate category tab
  2. Click + Add Equipment button
  3. Fill in: Equipment Tag, Description, Installation, Make, Model, Serial No, Status
  4. Click Save

Updating Equipment Status

  1. Find the equipment in the registry
  2. Click the Edit icon in the row
  3. Update the Status field (Working / Not Working / Under MOH)
  4. If Not Working, provide the Reason
  5. Click Save

Equipment History

  1. Go to Equipment History in the sidebar
  2. Select type (Instrument or Equipment)
  3. Search and select the equipment tag
  4. View calibration history, replacement records, and maintenance logs

Work Orders

Create, track, and close maintenance work orders.

Creating a Work Order

  1. Navigate to Work Orders from the hub
  2. Click + New Work Order
  3. Fill in: Title, Description, Priority, Type, Department, Equipment Tag
  4. Set Scheduled Date and Assigned To
  5. Click Create

Managing Work Orders

  1. Toggle between Kanban and List views
  2. Click any work order card to view details
  3. To close a WO: click Close Work Order and enter completion notes
  4. Admin users can delete work orders from the detail panel

Digital Logbook

Record daily equipment running hours, gas compression logs, and electrical test data.

Running Hours Log

  1. Navigate to Digital Logbook from the hub
  2. Select Running Hours tab
  3. Filter by installation using the dropdown
  4. Click + Add Entry
  5. Select Installation first - this filters the equipment dropdown
  6. Select Equipment from the filtered list
  7. Fill in: Date, Shift, Run Hours, Cumulative Hours, Status
  8. Enter operating parameters (Temp, Pressure, etc.)
  9. Click Save

Gas Compression Log

  1. Select Compression Log tab
  2. Filter by installation
  3. Click + Add Entry
  4. Select Installation first - this populates gas compressors (GCP/GLC/GAS only)
  5. Select Gas Compressor from the filtered list
  6. Enter compression data: Gas Volume, Run Hours, Flow Rate, Pressures, Temperatures
  7. Click Save
Tip: Click any compressor tag in the table to view its full equipment history in the Equipment Master module.

Configuring Parameters

  1. Click the Columns button in Running Hours Log
  2. Load a preset (Motor, Pump, Compressor, Generator) or add custom parameters
  3. Save your configuration as a template for future use

Major Overhaul (MOH)

Plan, track, and execute major equipment overhauls based on D-check intervals.

Viewing MOH Records

  1. Navigate to Major Overhaul from the hub
  2. The dashboard shows upcoming and overdue MOH based on running hours vs D-check interval
  3. Click MOH Records in the sidebar to see all records
  4. Filter by status (Planned, In Progress, Completed) or installation

Initiating a New MOH

  1. Click + Initiate MOH
  2. Enter: MOH Number, Equipment Tag, Installation, Priority
  3. Set planned dates and estimated cost
  4. Click Save

Updating MOH Progress

  1. Find the MOH record in the table
  2. Click Edit icon to open the full edit form
  3. Update: Status, Priority, Assigned To, Running Hours, D-Check Interval
  4. Add: Scope of Work, Findings, Actions Taken
  5. Set actual dates and costs as work progresses
  6. Click Update

Quick Status Changes

  1. For PLANNED records: Click the Play icon to start (moves to IN_PROGRESS)
  2. For IN_PROGRESS records: Click the Check icon to complete

Calibration

Track instrument calibration schedules, record results, and monitor compliance.

Calibration Dashboard

  1. Navigate to Calibration from the hub
  2. The dashboard shows: Total Instruments, Due for Calibration, Overdue, Calibrated This Month
  3. Tables show due and overdue instruments with their last calibration dates

Recording a Calibration Event

  1. Go to Calibration Records in the sidebar
  2. Click + New Calibration
  3. Select Instrument Tag (searches by tag ID or description)
  4. Fill in: Calibration Date, Standard Used, Result (PASS/FAIL), Performed By
  5. Add calibration points if needed
  6. Click Save

Instrument Master

  1. Go to Instruments in the Equipment Master sidebar
  2. View all instruments with their calibration status and frequency
  3. Add new instruments or update existing ones

Audit

Track audit observations, assign corrective actions, and monitor compliance.

Creating an Audit Observation

  1. Navigate to Audit from the hub
  2. Go to the Observations tab
  3. Click + New Observation
  4. Fill in: Agency, Audit Date, Installation, Department, Service, Category, Severity
  5. Enter the observation details, reference, and target date
  6. Click Create

Managing Actions

  1. Click View on any observation to see its details
  2. Use Add Action to assign corrective actions
  3. Track action status from the Action Tracking tab
  4. Update action status using the dropdown in the table

Dashboard

The Audit Dashboard shows total observations, open/closed counts, overdue items, and breakdowns by agency, service, and severity.

Procurement

Manage procurement cases from request to purchase order.

Creating a Procurement Case

  1. Navigate to Procurement from the hub
  2. Click + Create Case
  3. Fill in: Title, Description, Department, Budget, Priority
  4. Add line items with quantities and specifications
  5. Submit for approval

Other Modules

Energy

Monitor energy consumption and efficiency. Enter meter readings, track trends, and generate energy reports.

Workshop

Manage workshop operations, engine overhauls, and repair tracking with ISO 14224 compliance.

Stock & Inventory

Track material stock levels, generate MRP requirements, and manage reorder points.

Contracts

Manage AMC contracts, track expiry dates, and monitor contract compliance.

Manuals & Drawings

Central document repository. Upload, organize, and search technical manuals and drawings.

Training

Track employee training records, certifications, and upcoming training schedules.

Reports

Generate cross-module reports with export to Excel/PDF. Includes dashboards and analytics.

Collaboration & Feedback

Team messaging, task assignments, and feedback collection.

Admin Guide

Administrative functions available only to users with the ADMIN role.

User Management

  1. Navigate to Manpower from the hub
  2. View all users and their roles
  3. Create new users or update existing user permissions

Deleting Records

Admin Only: Delete buttons are visible only to ADMIN users. All deletions are permanent and require confirmation.

LogbookRunning hours and compression log entriesClick trash icon in the row
AuditObservations and actionsClick trash icon in the row

ContractsContract recordsVia contracts management

Data Seeding

Initial data (equipment, instruments, installations, calibration history) is seeded during system deployment. Contact the system administrator to re-run seed scripts if data needs to be refreshed.

Settings

  1. Navigate to Settings from the hub
  2. Configure system-wide parameters
  3. Manage notification preferences
  4. View system health and diagnostics

Theme Preferences

Switch between Light, Dark, and Sepia themes using the theme selector in the sidebar footer.
